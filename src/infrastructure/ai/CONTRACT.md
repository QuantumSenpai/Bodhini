# AI form-label client contract

This module is not connected to scanning or review. A future proxy supplies the HTTPS endpoint and keeps provider credentials and prompts outside the app.

The caller supplies label-only input and a local `AiRequestScope`: a unique `formSessionId` for each form, a `revision` incremented after local field changes, and a new `attemptId` for every request. The client copies that scope into a successful suggestion result. The caller must pass its current scope to `mergeAiSuggestions`; a mismatch leaves the local fields unchanged. Scope values and original field IDs stay on the device. Do not reuse a scope for a different form or request.

The wire request has only `language` (`en`, `hi`, or `bn`) and `labels` containing generated positional IDs and sanitized text. Sanitization runs immediately before transport. For each label it applies Unicode NFKC normalization, collapses JavaScript Unicode whitespace, checks 120 code points, drops text containing `@`, masks supported patterns, and checks the final transmitted label against 120 code points again. It accepts at most 40 input labels, rejects a third distinct masked label, and caps the serialized request at 16,384 UTF-8 bytes. It masks Unicode decimal digit runs of five or more, numeric dates with optional spaces around separators, English month-name dates with Unicode decimal digits, ASCII PAN patterns with optional spaces, and 12 or 16 decimal digits grouped in fours. Other number forms, arbitrary names, addresses, and other personal information may remain in a label. Sanitization is a pattern filter, not proof that a request is free of personal information.

The proxy response is exactly `{ "suggestions": [] }`, with entries of `{ "id": "f0", "action": "map", "key": "FULL_NAME" }` or `{ "id": "f0", "action": "manual", "type": "SIGNATURE" }` using allowed keys and types. The client rejects the entire response when any entry is invalid. It validates a maximum of 8,192 UTF-8 bytes after reading the response. The `Content-Length` check can reject an oversized declared response before calling `text()`, but React Native's installed fetch uses XHR and can buffer the body before that check. A missing or false-low header is not a network memory limit.

Before enabling the feature, the proxy must cap incoming request bodies, bound provider output, use a bounded upstream read or equivalent resource control, and enforce the 8,192-byte maximum serialized response before sending it. It must not return document values or log labels or response bodies. Live integration also needs default-off localized consent, AI provenance in review, explicit confirmation, and a current-scope check after every asynchronous result.
